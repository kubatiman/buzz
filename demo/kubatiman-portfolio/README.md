# Kubatiman — Artist Portfolio Demo

A single-file, dependency-free portfolio site for **Kubatiman**, a fictional
musician working in cinematic / ambient-electro, built as a standalone design
demo (unrelated to the Buzz relay/app codebase).

- Black-first palette with violet + cyan accents (and a touch of ember)
- Animated hero: drifting canvas fog blobs, an idle ambient waveform, and a
  staggered headline reveal
- Featured release with tracklist, discography grid, bio, visuals grid, and a
  rotating press-quote carousel — all vanilla JS, no build step

## View it

Open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 8080 --directory demo/kubatiman-portfolio
```

Then visit `http://localhost:8080`.
