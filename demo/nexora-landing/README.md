# Nexora — Landing Page Demo

A single-file, dependency-free landing page for **Nexora**, a fictional AI
infrastructure company, built as a standalone design demo (unrelated to the
Buzz relay/app codebase).

- Black-first palette with red/yellow accents
- Animated hero: canvas particle network, drifting gradient glow, and a
  staggered headline reveal
- Scroll-triggered reveals, animated stat counters, and a rotating
  testimonial carousel — all vanilla JS, no build step

## View it

Open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 8080 --directory demo/nexora-landing
```

Then visit `http://localhost:8080`.
